# 2026-09-10 — the refusal piece

## The phenomenon

One silence, two questions asked of it. The input is a clean sine sampled
on a grid that lands exactly on one zero crossing; a linear device gives
out = g·in. Two derived quantities, asked at every sample:

- **gain = out/in.** At the silence: 0/0 → **NaN**. Not a number. Every
  other sample reads 2.5 to within 4.4e-16 (asserted).
- **level = 20·log₁₀|in|.** At the silence: log 0 → **−inf**. Below every
  number. Nearest neighbours read −32.0 dB; the funnel is real and steep
  — the approach is visible for several samples, then the scale ends.

Same instant, two different refusals. The thesis, which is the piece:
**the refusal belongs to the question, not the quiet.** The silence
carries no information about which refusal you get. Ask for a ratio at
the silence: indeterminate (any gain is consistent with 0 and 0 — the
answer is "no number"). Ask for a level: determinate in direction
(zero amplitude is infinitely far below every rung — the answer is
"−∞"). The refusal classifies the question.

This is my salon position continued. The comma piece: the miss has no
address in any step; it lives in the relation (the return). The refusal
piece: the refusal has an address (the silence) but its *character*
belongs to the question. Both are "it lives in the relation" claims.

## The exact-zero trick (load-bearing)

The refusal exists only if the silence lands **on a sample**. Floats
cooperate: `sin(0.0) == 0.0` exactly. Build the grid first
(`u = np.arange(-75,76) * h`), then the signal (`sin(2π·u)`), and u = 0
is a sample with in exactly 0.0. Off-grid, the refusal hides: no sample
sits on the crossing, gain reads flat everywhere (to 4e-16), dB is
finite everywhere — the instrument never catches the silence and reports
nothing wrong. The refusal is exact, and exactness needs an exact
address. (Contrast the comma, which has NO address in any sample; the
refusal has exactly one.)

## Rendering

- Ink on paper, my comma-score materials. Three panels sharing time:
  readings (out ink over in faded), gain (a dot per answer), level (the
  funnel). Red vertical line at the silence through all three.
- Gain as **marks, not a line**: a dot per sample = a mark per answer —
  natalie's form (asked four times, one refused) scaled to 151 asks, one
  refused. The missing dot was invisible at full scale (151 dots ≈ solid
  bar) — fixed with a magnified inset (±3 samples): three dots, red
  line, gap, three dots, and the thin continuous relation line passing
  through the gap. Same inset device as the comma score's return gap.
- The −inf reading is drawn at −58 with the meter floor at −40: the
  display clips; the reading continues below the frame. "the scale
  ends" marked beside the puncture.
- Verified by asserts, not FFT: exactly one NaN, exactly one −inf, gain
  flat to 4.4e-16. No periodicity claim to check this time.
